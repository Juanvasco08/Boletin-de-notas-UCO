# Arquitectura de Asistentes - Boletín UCO

Este archivo define el ecosistema de agentes, utilidades y reglas de calidad para la refactorización Orientada a Objetos de nuestro proyecto académico.

## Principios del Sistema
- **Idioma**: Todo el flujo de comunicación, commits y logs se maneja en español.
- **Rigor en POO**: Cumplimiento estricto del modelo de dominio (`Persona`, `Estudiante`, `Profesor`, `Main`).
- **Control de Versiones**: Protección de la rama `main` y trabajo ordenado en `development`.

## Agentes Disponibles
1. **`git-mentor`**: Asistente dedicado a la disciplina de commits y flujo de trabajo Git.
2. **`revisor-poo`**: Auditor especializado en encapsulamiento, herencia y limpieza de código Java.
