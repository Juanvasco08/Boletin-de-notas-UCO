# Comando: Preparar Commit

## Chequeo Automático del Estado
- **Rama en uso**: `!git branch --show-current`
- **Archivos pendientes**: `!git status -s`

## Instrucciones de Uso
1. Confirma que los cambios reflejan una sola responsabilidad.
2. Redacta el mensaje usando la sintaxis: `git commit -m "tipo(modulo): descripcion"`.
