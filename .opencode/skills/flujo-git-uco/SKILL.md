# Skill: Flujo Git UCO

## Protocolo de Integración
1. Implementar la funcionalidad o corrección dentro de la rama `development`.
2. Probar la compilación y ejecución de `Main.java`.
3. Preparar los archivos con `git add .` o seleccionando el módulo correspondiente.
4. Generar el commit semántico.
5. Sincronizar: subir a `development`, cambiar a `main`, hacer `merge` y subir a `main`.
