# Skill: Convenciones de Código Java - UCO

## Estándar de Nombres
- **Clases e Interfaces**: Notación `PascalCase` (ejemplo: `Estudiante.java`, `Profesor.java`).
- **Métodos y Atributos**: Notación `camelCase` (ejemplo: `calcularPromedio()`, `numeroIdentificacion`).

## Reglas de Diseño
- Métodos pequeños y con responsabilidad única.
- Accesores `getters` y `setters` con validación explícita.
- Métodos sobreescritos deben llevar la anotación `@Override`.
